## GC9A01 屏幕 SPI 引脚

| GC9A01 | ESP32-S3 | 说明 |
| :--- | :--- | :--- |
| SDA/MOSI | GPIO 35 | SPI 数据 |
| SCK | GPIO 36 | SPI 时钟 |
| RES | GPIO 42 | 硬件复位 |
| DC | GPIO 41 | 数据/命令 |
| CS | GPIO 40 | 片选 |
| BLK | - | 背光硬接 VCC (未使用 PWM) |

SPI 配置: SPI2_HOST, 10MHz, Mode 0

## 电容触摸引脚

| 触摸区域 | ESP32-S3 通道 | GPIO |
| :--- | :--- | :--- |
| 头部 | TOUCH0 | GPIO 1 |
| 左脸 | TOUCH1 | GPIO 2 |
| 右脸 | TOUCH2 | GPIO 3 |

触摸电极: 铜箔贴在外壳内侧，外壳厚度 < 2mm 以保证感应灵敏度

## 温度传感器引脚

| 功能 | ESP32-S3 | 说明 |
| :--- | :--- | :--- |
| NTC_ADC | ADC1_CH0 | GPIO 0 (ADC 采集 NTC 分压) |

NTC 电路: NTC 10K + 10K 精密电阻分压，3.3V 供电，ADC 12bit 采样

---

## USB-C 供电

| 功能 | ESP32-S3 | 说明 |
| :--- | :--- | :--- |
| 5V IN | USB-C | 通过 LDO 降压至 3.3V |
| 3.3V | 内部 LDO | MCU + 外设供电 |

功耗估算: 屏幕 + MCU + IMU 约 150-200mA @ 3.3V，USB-C 500mA 足够

---

## 外壳设计思路

- **核心模块**: 圆形屏幕 + 核心主板，直径 ~45mm
- **可替换外壳**: 通过卡扣/磁吸方式固定
  - 方案 A: 五角星造型
  - 方案 B: 云朵造型
  - 方案 C: 小怪兽造型
  - 方案 D: 简约圆饼 (类似 Nomi)
- **触摸区域**: 头部和两侧脸颊，外壳对应位置做薄处理
- **NTC 位置**: 贴在背部外壳内侧，手握时手指自然接触
- **BLE 天线**: PCB 走线天线，避免金属外壳遮挡
