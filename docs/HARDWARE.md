# 硬件清单 (BOM)

## 核心组件

| 组件 | 型号/规格 | 说明 |
| :--- | :--- | :--- |
| **MCU** | ESP32-S3 (N16R8) | 16MB Flash, 8MB PSRAM |
| **屏幕** | GC9A01 | 240x240 圆形 SPI LCD |
| **触摸** | 电容触摸通道 / 外部触摸片 | ESP32-S3 自带触摸控制器 |
| **IMU** | MPU6050 / QMI8658 | 6轴加速度+陀螺仪 |
| **麦克风** | INMP441 / MSM261S4030 | I2S 数字麦 |
| **光感** | BH1750 / VEML7700 | I2C 光照传感器 |
| **喇叭** | 3W 4Ω 单声道 + MAX98357A | I2S 音频功放 |

## GC9A01 引脚定义 (参考)

| GC9A01 | ESP32-S3 |
| :--- | :--- |
| SDA/MOSI | GPIO 11 |
| SCK | GPIO 12 |
| RES | GPIO 5 |
| DC | GPIO 4 |
| CS | GPIO 6 |
| BLK | GPIO 7 (PWM 控亮度) |

## 传感器 I2C 引脚

| 功能 | ESP32-S3 |
| :--- | :--- |
| I2C_SDA | GPIO 8 |
| I2C_SCL | GPIO 9 |

## 麦克风 I2S 引脚

| 功能 | ESP32-S3 |
| :--- | :--- |
| I2S_BCLK | GPIO 16 |
| I2S_LRC | GPIO 17 |
| I2S_DIN | GPIO 18 |

## 外壳设计思路

- **核心模块**：圆形屏幕 + 核心主板
- **可替换外壳**：通过卡扣/磁吸方式固定
  - 方案A：五角星造型
  - 方案B：云朵造型
  - 方案C：小怪兽造型
  - 方案D：简约圆饼（类似Nomi）
