# 交互与关系系统设计

## 四种体感交互

Harti 的所有交互都是身体的、直觉的，无需学习。

### 触摸交互

| 交互 | 检测方式 | Harti 反应 |
|------|---------|-----------|
| **摸头** | 电容触摸 (外壳顶部 TOUCH0 / GPIO1) | 眯眼笑 + 腮红，持续摸会慢慢闭眼享受 |

触摸检测要点：
- 使用 ESP32-S3 内置电容触摸外设，无需额外芯片
- 触摸电极贴在外壳内侧，外壳作为感应面
- 检测阈值需根据外壳厚度调试，建议加自适应校准
- 防误触：连续触摸 > 50ms 才触发事件

### 摇晃交互

| 交互 | 检测方式 | Harti 反应 |
|------|---------|-----------|
| **摇晃** | IMU 加速度幅值 > 2.5g，持续 > 300ms | 先惊讶 (大瞳孔)，然后晕乎 (眼睛转圈) |
| **轻拍** | IMU Z 轴短脉冲 (< 100ms)，幅值 1.5-2.5g | 眨眼抬头看你，连拍会委屈 |
| **翻转** | IMU 重力方向反转 | 惊恐翻白眼，翻回来后迷糊 |

摇晃检测要点：
- 采样率 100Hz，使用滑动窗口计算加速度幅值
- 轻拍和摇晃通过持续时间区分：< 100ms 为轻拍，> 300ms 为摇晃
- 翻转通过重力方向检测，Z 轴符号反转持续 > 500ms 确认

### 温度交互

| 交互 | 检测方式 | Harti 反应 |
|------|---------|-----------|
| **捂热** | NTC 温度上升 > 2°C/5s | 渐变开心表情，"暖到了"的小脸红 |
| **变冷** | NTC 温度 < 15°C | 缩小 + 发抖动画 |
| **骤变** | 温度变化 > 5°C/10s | 惊讶反应，根据方向不同 |
| **双击查看** | 双拍外壳 | 切换到温度表盘显示 2 秒 |

温度检测要点：
- NTC 热敏电阻 + ADC 采样，贴在外壳内侧
- 采样率 1Hz (温度变化慢，不需要高频)
- 检测手温需要 1-2 秒响应，NTC 选小体积快响应型号
- 温度表盘利用圆屏天然优势：中心显示数字，外圈渐变色带

## 碰一碰关系系统

### 通信机制

- **技术**: ESP32-S3 内置 BLE 5.0
- **发现**: 低功耗广播，Harti 专用 Service UUID
- **范围**: 约 10cm (降低发射功率，实现"碰一碰"的物理仪式感)
- **连接**: 自动配对，无需确认，靠近即连
- **数据交换**: BLE GATT 写入，交换设备 ID + 关系数据

### 五级关系

| 等级 | 名称 | 碰一碰反应 | 升级条件 | 解锁内容 |
|------|------|-----------|---------|---------|
| Lv.0 | 陌生人 | 好奇地看对方，眨眨眼 | 初始状态 | 基础碰面动画 |
| Lv.1 | 点头之交 | 微笑点头，小星星闪一下 | 碰 1 次 | 点头动画 |
| Lv.2 | 朋友 | 开心跳动 + 送出一颗小心心 | 累计 3 次 | 心心动画 |
| Lv.3 | 好友 | 激动转圈 + 双方同时出现彩虹装饰 | 累计 6 次 | 彩虹装饰 |
| Lv.4 | 挚友 | 眼睛变成心形 + 专属金光特效 | 累计 10 次 | 心形眼 + 金光 |

### 关系数据结构

```c
typedef struct {
    uint8_t  ble_id[6];       // 对方 BLE 地址
    uint8_t  level;           // 关系等级 0-4
    uint8_t  meet_count;      // 碰面总次数
    uint32_t last_seen;       // 上次见面时间 (Unix 时间戳)
    char     nickname[8];     // 对方昵称 (可选)
} friend_record_t;
```

每条记录 20 字节，最多 16 个朋友 = 320 字节。

### 存储与持久化

- 使用 ESP32-S3 的 NVS (Non-Volatile Storage)
- Key 命名: `friend_00` ~ `friend_0f`
- 每次碰一碰后写入，磨损均衡由 NVS 自动处理
- 关系衰减: 每 7 天不碰面，meet_count 对衰减系数减 1 (最低不降级，只是"好久不见"反应)

### 冷启动解法

- 单人模式下 Harti 有完整的日常行为，不依赖碰一碰
- 首次开机引导动画: "想交朋友？找另一只 Harti 碰一碰！"
- 如果附近无其他 Harti，每 5 分钟扫描一次 (低功耗)

## 事件系统

所有传感器事件统一通过 FreeRTOS 队列传递给行为模块：

```c
typedef enum {
    EVT_TOUCH_HEAD,      // 摸头
    EVT_TOUCH_RELEASE,   // 手离开
    EVT_SHAKE,           // 摇晃
    EVT_TAP,             // 轻拍
    EVT_FLIP,            // 翻转
    EVT_WARM_UP,         // 温度上升 (被捂热)
    EVT_COLD_DOWN,       // 温度骤降
    EVT_BLE_MEET,        // 碰一碰遇到新朋友
    EVT_BLE_FRIEND,      // 碰一碰遇到老朋友
    EVT_NONE
} sensor_event_t;
```

事件附带数据：

```c
typedef struct {
    sensor_event_t type;
    float value; // 温度数值 / 加速度幅值 / 关系等级
} sensor_event_msg_t;
```
