# 萌系表情形象重绘 设计文档 (Kawaii Expression Redesign)

**日期:** 2026-06-11
**目标:** 把 harti 全部 9 种 sprite 风格的表情形象"萌化"——更美观可爱——并增加眼睛灵动动画细节，全程严格遵守黑白配色，零数据结构改动。

**主基调（方向 B · 萌系亮眼）:** 黑底圆屏上，眼睛从「白圈 + 白虹膜 + 黑高光点」翻转为「大实心白眼 + 大黑瞳 + 双白色星光」；正向表情加腮红；嘴形加粗柔化；适度放大眼睛比例。黑瞳便于体现视线方向（符合现有规范）。

---

## 架构与组织

整体改动是现有 5 层渲染管线（animator → micro → prop → vivid → temperament → renderer）之上的叠加式增强，分两类：

1. **共享眼睛灵动动画** — 在 `face_micro.c` 调制现有 `eye_params_t` 参数，9 种风格一次实现、同时受益。
2. **逐风格形象重绘** — 每个 `sprites/sprite_*.c` 各自的眼/嘴/腮红绘制，VECTOR 为完整旗舰参考，其余 8 风格按统一原则适配各自身份。

**严格约束:**
- 仅 `RGB565(0,0,0)`（黑）和 `RGB565(255,255,255)`（白），任何灰阶/腮红用 Bayer 点阵抖动（复用 `bayer_accept` / `blend_colors`）模拟。
- 不修改 `face_model.h` / `face_state_t` schema，全部复用现有 `eye_params_t` 字段，向后兼容。
- 每改一个文件就 `idf.py build` 通过 + 黑白配色审查后提交。

**复用的现有 `eye_params_t` 字段:** `position.dx/dy`、`top_lid_mid.dy`、`bot_lid_mid.dy`、`iris_center.dx/dy`、`pupil_scale`、`iris_detail`、`shine_intensity`、`eyelash`。

---

## 第 1 部分：眼睛灵动动画（共享层 `face_micro.c`）

全部为 `micro_animator_apply()` 内的叠加调制，无新数据结构。关闭任一项不影响其它层。

### 1.1 高光微闪 (catchlight shimmer)
给 `shine_intensity` 叠加低幅正弦，让星光像水光一样轻轻呼吸。
- 频率 ≈ 0.2 Hz，幅度 ±0.12，叠加后 clamp 到 [0, 1]。

### 1.2 好奇瞳孔游走 (idle pupil drift)
在非扫视（saccade）空闲期，给 `iris_center.dx/dy` 叠加慢速李萨如轨迹，眼神像在轻轻打量。
- dx: 0.13 Hz，dy: 0.17 Hz，幅度约 ±0.04（小，避免与既有 saccade 抢戏）。
- 仅在当前不处于 saccade 状态时叠加。

### 1.3 星瞳 / 爱心瞳脉动
当前表情为 `EMOTION_DIZZY`（星瞳）或 `EMOTION_HEART_EYES`（爱心瞳）时，给 `iris_detail` 叠加心跳式脉动，让星星/爱心一搏一搏放大缩小。
- 频率 ≈ 1.6 Hz，幅度 ±0.18，叠加后 clamp 到 [0, 1]。
- 当前表情通过 `micro_animator_set_expression()` 已记录的 id 读取。

### 1.4 眨眼回弹 (blink squash rebound)
眨眼闭合→睁开瞬间，上眼睑 `top_lid_mid.dy` 短暂过冲到负值（眼睛比平时睁大约 8%）再回落，眨眼带俏皮"弹一下"。
- 挂在现有眨眼状态机睁眼完成节点；回弹时长约 120ms，过冲量 ≈ -0.08，用 `(1-t)` 衰减回 0。

## 第 2 部分：VECTOR 旗舰形象重绘 (`sprites/sprite_vector.c`)

核心是把所有"有瞳孔"的眼型从白虹膜+黑点翻转为黑瞳+白星光，并放大、加腮红、柔化嘴形。

### 2.1 眼睛翻转（关键改动）
当前 `V_EYE_NORMAL`：白圈轮廓 + 白虹膜盘 + 黑色 catchlight 点。改为：
- **大实心白眼盘**（`PAL_SCLERA`，半径较现状放大约 8%）。
- **大黑瞳**（`PAL_PUPIL`，半径约眼半径 0.5，随 `pupil_scale` 缩放），位置受 `iris_center` 驱动。
- **双白色星光**：大星光（眼半径 ≈ 0.18，左上）+ 小星光（≈ 0.08，右下），强度随 `shine_intensity`（含第 1.1 节微闪）。星光为 `PAL_SCLERA`（白）画在黑瞳内。
- 同一套"黑瞳+白星光"应用到所有有瞳孔的眼型：`V_EYE_NORMAL`、`V_EYE_SURPRISED`、`V_EYE_SAD`、`V_EYE_BORED`、`V_EYE_ANGRY`。

### 2.2 各眼型萌化细节
- **NORMAL（平静）:** 正圆大白眼，黑瞳居中，双星光。
- **HAPPY（开心）:** 保留上弯月牙（`∩` 拱形白弧），加粗到约 7px；配腮红。
- **SURPRISED（惊讶）:** 放大白眼，缩小黑瞳并上移，单星光。
- **SAD（难过）:** 黑瞳下沉，上眼睑用黑色弧形遮住眼上缘营造垂眼；保留泪滴。
- **ANGRY（生气）:** 倒 V 粗眉 + 眯眼（白眼下半弧）+ 小黑瞳，无腮红。
- **HEART_EYES（花痴）:** 黑色爱心瞳（复用现有 heart pupil 数学）+ 星光 + 腮红 + 大笑。
- **DIZZY / 星瞳:** 白圈 + 五角星填充（保留现有），叠加第 1.3 节脉动。

### 2.3 腮红 (blush)
正向表情（HAPPY、CONTENT、HEART_EYES、WARM）在双颊加腮红：椭圆区域用 `bayer_accept` 点阵抖动出白色斑（复用现有 `draw_blush` 逻辑），强度随表情。

### 2.4 嘴形柔化
所有嘴型描边加粗到 3.5–4px、转角圆化（`stroke_linecap=round` 等效的扫描线圆头），开口笑（V_SMILE / V_LAUGH）用黑色填充 + 白色描边的"D"形，更饱满。

## 第 3 部分：其余 8 风格可爱化扫描

统一 4 原则（放大眼 / 黑瞳+白星光 / 腮红 / 柔嘴）套用并保留各自身份：

| 风格 | 萌化做法 | 特殊约束 |
|------|----------|----------|
| **classic** | 与 VECTOR 同路：黑瞳+双白星光+腮红+柔嘴，最接近旗舰 | 无 |
| **lineart** | 保留线稿：眼眶画圆润，瞳内留白色高光缺口，腮红用斜线/点阵 | 仅线条不填实 |
| **nova**（白脸黑五官） | 反相：黑瞳内挖**白色**星光缺口；腮红在白脸上用**黑色**点阵 | 颜色逻辑反过来 |
| **cat** | 大眼+竖椭圆瞳+白星光+腮红，胡须/耳朵线条柔化 | 保留猫脸/胡须 |
| **pixel** | 瞳=黑色方块，星光=单个白像素，腮红=棋盘格像素 | 全方块无平滑曲线 |
| **robot** | 屏幕眼圆润化+反光像素高光，腮红扫描线点阵，天线/外框柔化 | 机械感保留 |
| **pig** | 大眼+黑瞳白星光+腮红，猪鼻保留略圆润 | 保留猪鼻 |
| **chibi** | 强化双星光、加腮红、比例微调更圆 | 无 |

每种风格独立适配，单独编译+审查+提交。

## 第 4 部分：约束与验证

- **黑白审查:** 每个改动文件提交前，确认绘制代码只产生 `PAL_*`（已是黑/白）或 `bayer_accept`/`blend_colors` 抖动结果，无新增第三色常量。
- **编译验证:** 每文件 `. ~/.espressif/v6.0.1/esp-idf/export.sh && idf.py build` 通过（`-Werror=missing-field-initializers` 仍启用）。
- **向后兼容:** 无 `face_model.h` / `face_state_t` 改动；现有表情定义与分类器（`classify_eye` / `classify_mouth`）逻辑不破坏，仅替换各眼/嘴类型的绘制实现。
- **解耦:** 第 1 部分动画（`face_micro.c`）与第 2/3 部分形象（`sprite_*.c`）相互独立，可分别开关、分别验证。

## 实施顺序建议

1. 第 1 部分眼睛灵动动画（`face_micro.c`）——一次性、全风格受益、风险低。
2. 第 2 部分 VECTOR 旗舰重绘——确立"萌系亮眼"参考实现。
3. 第 3 部分其余 8 风格——以 classic 优先（最接近 VECTOR），逐个适配、编译、审查、提交。

每步独立编译+提交，便于回退与逐步验证。
