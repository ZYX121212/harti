# Harti Pet 产品定义

## 一句话定位

Harti 是一个 ￥99 的桌面情感宠物，用圆屏大眼睛解压，用碰一碰交友。

## 核心体验

```
         解压视觉
        /        \
  体感互动 ─────── 碰一碰社交
```

1. **解压视觉** — 圆屏大眼睛 + 流畅动画 + 双色主题，摆在桌上看着就治愈
2. **体感互动** — 摸头开心、摇晃惊喜、捂热变暖、轻拍回应，四种直觉交互无需学习
3. **碰一碰社交** — 两只 Harti 靠近自动连接，关系从陌生到挚友逐级升温，每级解锁新反应

## 目标受众

| 受众 | 需求 | 满足方式 |
|------|------|---------|
| 大众消费者 | 开箱即用，好看好玩 | 四种体感交互 + 碰一碰，无需学习 |
| 科技爱好者 | 可定制、可编程 | 开源表情 SDK，社区表情包一键刷入 |

## 产品规格

- **价格**: ￥99
- **屏幕**: GC9A01 240x240 圆形 LCD
- **核心芯片**: ESP32-S3 (16MB Flash, 8MB PSRAM)
- **交互传感器**: 电容触摸 / 6轴 IMU / NTC 温度 / BLE
- **续航**: USB-C 供电 (桌面常驻)
- **表情数**: 13 种预设 + 社区无限扩展

## 设计理念

### 解压优先

Harti 不是效率工具，而是情感出口。所有设计决策优先考虑「看着舒服、摸着开心」。

### 极简交互

没有按钮，没有菜单，没有 App。摸它、摇它、捂它、碰它——所有交互都是身体的、直觉的。

### 社交飞轮

```
用户 A 买 Harti → 日常使用觉得好看 → 给朋友 B 看
  → "碰一碰！" → B 也想买一个 → 两人关系升级
  → 解锁新表情 → 分享到社交媒体 → 吸引 C、D...
```

碰一碰是 Harti 的传播引擎：每个用户都是推销员，关系等级是留存钩子。

### 防止吃灰

桌面宠物最大的敌人是被遗忘。Harti 的应对：

1. **自发行为** — 闲置 30 秒后发呆、打哈欠、四处看，像真的在等你
2. **温度联动** — 环境温度变化时自动反应，不用你主动互动
3. **时间感知** — 早中晚有不同的默认表情 (早上困、中午精神、晚上瞌睡)
4. **关系衰减** — 太久不碰一碰，朋友关系会慢慢降级 (不消失，只是"好久不见")
