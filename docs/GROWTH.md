## 关键增长杠杆

### 1. 碰一碰 = 买两个

关系系统必须两人参与，这是最核心的增长飞轮：
- 单人用户会主动拉人："你也买一个我们碰一碰"
- 双人优惠降低门槛
- 关系等级制造持续互动动力

### 2. 关系等级 = 回访

朋友关系存在 Flash 里，不会因重启消失：
- 用户有动机持续碰一碰以升级关系
- "好久不见"衰减机制制造再互动理由
- 挚友解锁的心形眼是社交炫耀资本

### 3. 可拍短视频

碰一碰动画极其上镜，天然适合传播：
- 心形眼、彩虹装饰、小心心都是视觉记忆点
- 15 秒短视频足以展示完整碰一碰流程
- 不需要解说，画面自解释

### 4. 开源表情 = UGC

社区自制表情包让内容无限：
- 官方不需要生产所有内容
- 优秀表情包可以反向吸引新用户
- 表情包创作者自带粉丝

### 5. ￥99 价格

冲动消费阈值内：
- 不需要太多决策时间
- 送礼场景友好 (生日、节日)
- 相比 Nomi (￥400+) 有巨大价格优势

## 风险与应对

| 风险 | 严重性 | 应对 |
|------|--------|------|
| 碰一碰冷启动 (身边没有其他 Harti) | 高 | 单人模式体验完整，碰一碰是加分项而非必要功能 |
| 吃灰 (桌面宠物通病) | 高 | 自发行为 + 温度联动 + 时间感知 + 关系衰减 |
| 山寨跟进 | 中 | 开源社区壁垒 + 表情生态壁垒 + 关系数据壁垒 |
| 表情包质量参差 | 低 | 官方审核 + 社区评分 |
| BLE 配对失败/不稳定 | 中 | 碰一碰降级为纯视觉反馈 (看到对方但不连接) |
